    What license should I use for government flood data in Australia?
    Assistant
    Australian government datasets are commonly released under CC-BY-4.0, which requires attribution but allows commercial use. The STAC spec recommends using SPDX license identifiers. I've pre-selected CC-BY-4.0 for you — you can change it if your data has different terms.

    Should I include temporal extent even though it's a one-off event?
    Assistant
    Yes — the STAC specification requires either a datetime or a start_datetime/end_datetime pair. For event-based data like this flood, using a date range (22 Feb – 5 Mar 2023) captures the full duration of the event and makes it easier for temporal search queries.

    Can I add custom properties?
    Assistant
    Absolutely. STAC Items support additional properties beyond the core fields. Common geospatial properties include gsd (ground sample distance), eo:bands, and proj:epsg. For flood data, you might add a custom property like event:type or use the STAC Natural Hazards Extension.
